# SimpleAgentStore banner

The current README uses `simpleagentstore-banner.svg`, an editable, self-contained vector illustration authored for this repository. It uses no external fonts, scripts, tracking, or third-party logos. The typography and diagram are source-controlled and covered by the repository license.

The earlier `agentstore-banner.png` is retained as a historical asset. It was generated with the built-in image-generation tool at 2172 × 724 pixels (3:1), using the original AgentStore name. The historical prompt follows.

## Final prompt

```text
Use case: ads-marketing
Asset type: hero banner image for the GitHub README of AgentStore.
Primary request: a striking, editorial, premium developer-tool banner that instantly communicates a user-owned store shared across AI agents.
Scene/backdrop: dark charcoal, subtle fine grain, restrained soft illumination.
Subject: a beautifully rendered translucent architectural object-storage cube with a small stack of structured cards inside; a few precise luminous paths connect it to three small abstract client terminals. One shared store, multiple agents. Not a brain or knowledge graph.
Style/medium: sophisticated 3D editorial illustration with sharp graphic typography, understated and memorable rather than generic sci-fi.
Composition/framing: wide landscape banner approximately 3:1; oversized clear wordmark and short tagline occupy the left half, sculptural storage artwork on the right; generous margins and excellent legibility at GitHub README width.
Text (verbatim): "AgentStore" and underneath "Your data. Any agent."
Typography: very large clean geometric sans-serif wordmark, high contrast off-white; small but readable subtitle. Render both strings exactly once, no other text.
Materials/textures: smoked glass, matte graphite, subtle warm amber light within the stored cards; crisp edges, quiet studio lighting.
Constraints: no third-party logos, no robots, no brains, no network hairballs, no fake UI metrics, no watermarks, no extra text, no excessive neon. Artwork expresses portable shared objects, not semantic memory.
```
