# GitHub Pages artwork

The landing page uses `site/assets/shared-store.jpg`, created with the built-in
image generation tool for this project. The original PNG is preserved at
`docs/assets/shared-store-source.png`; the served JPEG is a compressed export
of the same artwork. It is conceptual artwork, not a product
screenshot or evidence of an integration. No external stock image is used.

## Generation prompt

Use case: ads-marketing. Asset type: a compact developer-product website hero illustration for SimpleAgentStore, a user-owned SQLite object store shared by AI agents, not memory or RAG. Create a premium minimalist isometric editorial 3D illustration on a uniform very light cool gray background #f6f8f7. One small, beautifully crafted translucent frosted-glass open-top archive box containing three crisp structured index cards. Cards have tiny abstract engraved key/value marks, no legible text. Three thin understated connector tracks converge into this single store from three simple small matte graphite terminal tiles, implying multiple agents using one shared store. Palette: light gray, graphite, one restrained lime green accent within stored cards. Precise industrial-design materials, soft ambient studio lighting, fine edges and believable shadows. Tight composition centered with generous clean margin, landscape 4:3. No lettering, no logos, no robots, no brains, no clouds, no network hairball, no decorative UI windows, no watermarks. This is conceptual artwork, not a product screenshot.
